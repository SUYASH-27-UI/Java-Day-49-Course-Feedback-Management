# Java Day 49 – Course Feedback Management System

## Description
A Java application that collects student feedback and calculates average course ratings.

## Features
- Submit student feedback.
- Display all feedback records.
- Search feedback by course.
- Calculate average course ratings.
- Count feedback entries per course.
- Save records in a text file.

## Files
- `Main.java` – Main Java application.
- `feedback.txt` – Sample feedback database.

## How to Compile
```bash
javac Main.java
```

## How to Run
```bash
java Main
```

## Concepts Used
- Object-Oriented Programming
- Classes and Objects
- Constructors
- ArrayList
- HashMap
- File Handling
- Exception Handling
- Average Calculation
